# Purple Parfait

**Dreamy pastel purple, two ways: airy cream for day, velvety cocoa for night.**

A soft, low-contrast lilac theme that stays gentle on your eyes through long sessions.

---

### Two Flavors, One Palette

| Theme | Mode | Vibe | Best For |
| :--- | :--- | :--- | :--- |
| **Cream** | Light| Warm vanilla + lilac mist: airy, sunlit, confectionery | Daylight, pair-programming, low-light eye strain |
| **Cocoa**| Dark| Deep plum + muted lavender: velvety, focused, late-night | Night coding, OLED screens, dark-mode purists |

Both share the same lilac core, so switching feels seamless.
